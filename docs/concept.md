# Concept

## 何を作るか

ブラウザで遊べる**ミニゲーム集**（仮称：MiniGameSuite）。
トップ画面にゲームの一覧が並び、選ぶとそのゲームで遊べる。

## 誰のためか

- 作る人：プログラミング教室の中学生チーム。1人1ゲームを担当する
- 遊ぶ人：インターネット上の誰でも。ログインなしで、URL を開けばすぐ遊べる

## 一番の価値

「自分が作ったゲームが、本物の URL で誰にでも遊んでもらえる」こと。
作った本人が、家族や友だちに URL を送って見せられる。

## 最小スコープ（最初の公開）

- ゲーム一覧画面（トップ）
- ゲーム1本：「10秒れんだ」— 10秒間にボタンを何回押せるかを競う
- PC とスマホの両方で遊べる（クリック／タップだけで操作できる）

## 主な流れ

1. URL を開く → ゲーム一覧が出る
2. ゲームを選ぶ → そのゲームの画面へ
3. 遊び終わったら一覧へ戻れる

## 成功条件

- 公開 URL で、PC とスマホの両方から「10秒れんだ」を最後まで遊べる
- 新しいゲームを足すとき、土台を書き換えずに自分のディレクトリと登録1行で済む
- 生徒が自分のフォークから PR を出す前に、自分のパソコンで動作とテストを確かめられる

## やらないこと（今は）

- 記録・ランキングの保存、ログイン（必要になったら backlog で検討）
- 利用者が文字を入力して公開される機能（作る前に先生に相談する）

## 公開時に守ること

- 作者名はニックネームのみ。本名・学校名・顔写真は載せない
- 借りた素材は `docs/credits.md` に出典を書く
