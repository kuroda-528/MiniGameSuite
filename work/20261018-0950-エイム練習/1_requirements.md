# 1. Requirements — ゲーム「エイム練習」を追加する

## 目的

FPS（銃で的をねらうゲーム）の「エイム（ねらいを合わせる）」を練習できるミニゲームを、
2本目のゲームとして一覧に追加する。

## やること

- ゲーム「エイム練習」を作る（`src/games/aim/`、id は `aim`）
  - 画面は 2D。プレイエリアの中に丸い「的」が1つずつランダムな位置に出る
  - 「スタート」を押すと 20 秒のカウントダウンが始まる
  - 的をクリック（スマホはタップ）すると命中。すぐ次の的が別の場所に出る
  - 的以外の場所を押すと「ミス」として数える
  - 残り時間・命中数を表示する
  - 20 秒たったら終了し、結果を出す：命中数・命中率（命中 ÷ 押した回数）・平均反応時間（的が出てから当てるまで）
  - 「もう一回」で最初から遊べる
  - 命中の判定・命中率・反応時間・残り時間の計算は `rules.ts` の純粋関数にしてテストを書く
    （的の位置のランダムは外から渡せるようにして、テストで結果を固定できるようにする）
- `src/games/index.ts` に登録の1行を足す

## 受け入れ条件

- [ ] `npm run test` / `npm run typecheck` / `npm run lint` / `npm run build` がすべてエラーなしで通る
- [ ] ローカル（`npm run dev`）で、一覧に「エイム練習」が出て、選ぶと最後まで遊べて結果が出る
- [ ] 的を当てると次の的が別の場所に出る。的以外を押すとミスが増える
- [ ] 時間切れのあとは押しても数が変わらない
- [ ] スマホ幅の画面でも的がプレイエリアからはみ出さず、タップで遊べる
- [ ] 作業ブランチを push し、プレビュー URL で最後まで遊べる
- [ ] 作者名はニックネーム。コード・コミットに個人情報が入っていない
- [ ] 変更したのは `src/games/aim/` と `src/games/index.ts` の1行だけ

## やらないこと（スコープ外）

- 3D 表示・マウスを画面に固定する本物の FPS 操作（ゲームエンジンが必要になり、architecture の方針外）
- 効果音・画像素材（使うなら別作業で `docs/credits.md` とあわせて行う）
- 難易度選択・的が動く/小さくなるモード（やりたければ backlog へ）
- 記録・ランキングの保存
