# 1. Requirements — 2本目のゲーム「ぴったりストップ」を作る

## 目的

ミニゲーム集に2本目のゲーム「ぴったりストップ」を足す。
動くバーを真ん中でぴったり止める、1画面で遊べるシンプルなゲーム。

## やること

- ゲーム「ぴったりストップ」を作る（`src/games/stop/`）
  - 「スタート」を押すと、バーが左右に行ったり来たりして動き出す
  - バーは動いている間に**だんだん速くなる**
  - 「ストップ」ボタン（またはバー周りのタップ）で止める
  - 止めた位置が**真ん中に近いほど高得点**（100点満点）。結果として点数を表示する
  - 「もう一回」で最初から遊べる
  - 点数の計算とバーの位置・速さの計算は純粋関数（入力が同じなら答えも同じ関数）にして、テストを書く
- 一覧への登録
  - `src/games/index.ts` に1行足す
  - 作者名は `tamaya`（ニックネーム）
- PC とスマホの両方で、クリック／タップだけで遊べる

## 受け入れ条件

- [x] `npm run test` / `npm run typecheck` / `npm run lint` / `npm run build` がすべてエラーなしで通る
- [x] ローカル（`npm run dev`）で、一覧から「ぴったりストップ」を選び、最後まで遊んで点数が出る
- [x] バーが時間とともに速くなるのが目で見てわかる
- [x] 真ん中でぴったり止めると100点、端で止めると低い点になる（テストで確かめる）
- [x] `/games/stop` の URL を直接開いても 404 にならない（ローカルで確認。本番は push 後に確認）
- [ ] 作業ブランチを push すると、プレビュー URL でも遊べる
- [x] ゲーム内・コード・コミットに本名などの個人情報が入っていない（作者名は `tamaya` のみ）

## やらないこと（スコープ外）

- 記録・ランキングの保存（最高得点もその回の画面に出すだけ）
- 効果音・画像などの素材（図形と文字だけで作る。使う場合は先生に確認し `docs/credits.md` に書く）
- 複数回の合計点、難易度の選択
- 土台（`core/` や `features/`）や、他のゲーム（`renda/`）の変更
- main へのマージ（先生が行う）
