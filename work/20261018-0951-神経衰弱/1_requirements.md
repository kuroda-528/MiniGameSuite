# 1. Requirements — ゲーム「神経衰弱」を追加する

## 目的

ミニゲーム集の2本目として、カードをめくって同じ文字をそろえる「神経衰弱」を作る。
少ないめくり回数でぜんぶそろえることを目指す、1人用のゲームにする。

## やること

- ゲーム「神経衰弱」を作る（`src/games/memory/`）
  - カードは16枚（8ペア）。4×4にならべる
  - カードのおもてには数字や文字（例：A〜H）を書く。画像は使わない
  - 「スタート」を押すと、カードがシャッフル（ばらばらにまぜること）されて、すべて裏向きで並ぶ
  - カードをタップすると表になる。2枚めくったら次のどちらかになる
    - 同じ文字 → そろったカードは表のまま残る
    - ちがう文字 → 少し待ってから（1秒くらい）2枚とも裏にもどる
  - 2枚めくるごとに「めくった回数」を1ふやし、画面に表示する
  - すでに表のカード・そろったカードは、タップしても何も起きない
  - 2枚が裏にもどるのを待っているあいだは、3枚目をめくれない
  - 8ペアぜんぶそろったら、結果（めくった回数）を出す。「もう一回」で最初から遊べる
  - シャッフル・そろったかの判定・回数の計算は `rules.ts` に分けてテストを書く
- `src/games/index.ts` に登録の1行を足す
- 一覧に出す情報
  - タイトル：神経衰弱
  - 作者：リムルール
  - id：`memory`（神経衰弱の英語名。変えたければ承認のときに教えてください）

## 受け入れ条件

- [ ] `npm run test` / `npm run typecheck` / `npm run lint` / `npm run build` がすべてエラーなしで通る
- [ ] ローカル（`npm run dev`）で、一覧から「神経衰弱」を選び、8ペアぜんぶそろえて結果が出る
- [ ] ちがうカードを2枚めくると、少し待ってから裏にもどる
- [ ] 待っているあいだや、表になっているカードをタップしても、こわれない（回数がふえない）
- [ ] 「もう一回」を押すと、カードの並びが変わって最初から遊べる
- [ ] 作業ブランチを push し、プレビュー URL で最後まで遊べる
- [ ] プレビュー URL をスマホで開き、タップで遊べる（4×4のカードが押しやすい大きさ）
- [ ] ゲーム内・コード・コミットに本名などの個人情報が入っていない

## やらないこと（スコープ外）

- 2人対戦、かかった時間の計測、難しさ（枚数）の選択
- 記録・ベストスコアの保存
- 画像・効果音・カードをめくるアニメーション
- `src/core/` や `src/features/` の変更（必要になったら止めて先生に相談する）
