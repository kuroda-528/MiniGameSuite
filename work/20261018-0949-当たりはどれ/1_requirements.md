# 1. Requirements — 2本目のミニゲーム「当たりはどれ？」（最終的なタイトル：「反射神経チェック」）を作る

## 目的

2本目のミニゲーム（最終タイトル「反射神経チェック」、id: `atari`）を作り、タップ操作だけで遊べる
集中力系ゲームをゲーム一覧に追加する。

## やること

- `src/games/atari/` ディレクトリを作り、`MiniGame` を満たすゲームを実装する
  - id: `atari`（URL は `/games/atari`）
  - 画面に9色のタイルを並べる（毎回シャッフルして、9マス全部ちがう色になる）
  - 画面上部に「今回の当たり」（例：赤い四角）を表示する
  - 当たりをタップ → スコア +1、次の問題（新しい当たり・配置）に進む
  - 外れをタップ → その時点でゲームオーバー（作業途中でユーザーからの変更依頼により、当初の「外れは何も起きない」から変更）
  - 制限時間20秒。0秒になったら操作不可にして結果（スコア）を表示する
  - 「もう一回」ボタンで最初から遊べる
  - 残り時間・当たり判定・スコア計算は純粋関数にしてテストを書く（「10秒れんだ」と同じ方針）
- `src/games/index.ts` に登録用の import を1行追加する
- 作者名は仮の名前（「なぞ味のちゃぼ」）で登録する。あとで本人のニックネームに1行変更できる
  → 最終的に `IKA` に変更（途中で本名に近い「ITO」になっていたため、公開ルールに合わせて変更した）

## 受け入れ条件

- [x] `npm run test` / `npm run typecheck` / `npm run lint` / `npm run build` がすべてエラーなしで通る
- [x] ローカル（`npm run dev`）で一覧から「反射神経チェック」を選び、最後まで遊んでスコアが出る
- [x] `/games/atari` の URL を直接開いても 404 にならない（開発サーバーで確認。ステータス200）
- [ ] PC（クリック）・スマホ（タップ）のどちらでも最後まで遊べる
  - PC（クリック）：確認済み
  - スマホ（タップ）：**未確認。** スマホを同じWi-Fiにつなげず試したところ「サーバーが見つかりません」で開けなかった。
    ユーザー判断で、今回はこのまま未確認で進めることにした（ボタンは `onClick` のみで実装しており、
    タップでも同じイベントが発火する一般的なブラウザ仕様のため、動く可能性は高いが実機確認はしていない）
- [x] ゲーム内・コード・コミットに本名などの個人情報が入っていない（作者名を本名に近い「ITO」から「IKA」に変更して解消）
