# 1. Requirements — ゲーム「ぴったりストップ」を作る

## 目的

ミニゲーム集の2本目として、「ぴったりストップ」を作る。
動いている数字をボタンで止めて、ランダムに決まる目標の秒数（3〜10 秒）に、どれだけ近づけるかを競うゲーム。

## やること

- ゲーム「ぴったりストップ」を作る（`src/games/pittari/`）
  - 「スタート」を押すと、経過時間（秒）が 0.00 から数え上がる
  - 「ストップ」を押すと数字が止まり、結果を出す
  - 結果には「止めた時間」と「目標の秒数とのずれ」を出す（例：4.87 秒 → 0.13 秒はやい）
  - ずれの大きさに応じてひとこと評価を出す（例：ぴったり！／おしい！／もう少し！）
  - 「もう一回」で最初から遊べる
- 目標の秒数は、3〜10 秒（1 秒きざみ）からランダムに決まる（追加：2026-10-18 ユーザーの希望）
  - 「スタート」を押すたびに、3・4・5・6・7・8・9・10 のどれかが自動で決まる（選ぶボタンは作らない）
  - 「もう一回」では、前に出た秒数をのぞいてランダムに決める（同じ秒数が続かない）
  - 最初の「スタート前」の画面では、まだ秒数は決まっていない（「ねらいの秒数はスタートで決まるよ」と出す）
  - 遊んでいる間・結果の画面には、決まった目標秒数を出す
  - 評価の基準（0.05 / 0.3 / 1 秒）は、どの目標秒数でも同じにする
  - ランダムに決める部分は、乱数を外から渡せる関数にして、テストで確かめられるようにする
- 「ずれの計算」と「評価の判定」は純粋関数にして `rules.ts` に分け、テストを書く
- `src/games/index.ts` に登録の1行を足す
- 時間は `Date.now()` などの実際の時刻の差から出す（画面の更新回数で数えると、ずれるため）

## 受け入れ条件

- [ ] `npm run test` / `npm run typecheck` / `npm run lint` / `npm run build` がすべてエラーなしで通る
- [ ] ローカル（`npm run dev`）で、一覧から「ぴったりストップ」を選び、スタート→ストップ→結果→もう一回まで遊べる
- [ ] 目標秒数を 3〜10 のどれにしても、その秒数に近いほど良い評価が出る（`rules.test.ts` で境目の値を確かめる）
- [ ] スタートするたびに目標秒数が 3〜10 から決まり、その秒数が遊んでいる間と結果に出る
- [ ] 「もう一回」で、前と同じ秒数にならない（`rules.test.ts` で確かめる）
- [ ] `/games/pittari` の URL を直接開いても 404 にならない
- [ ] 作業ブランチを push し、プレビュー URL で最後まで遊べる
- [ ] スマホでタップして遊べる（ボタンが指で押せる大きさ）
- [ ] 作者名はニックネーム。ゲーム内・コード・コミットに個人情報が入っていない
